# מסדר הגלריה

**אלפי תמונות בטלפון ואף פעם לא מוצאים כלום?** סקיל ל-Claude Code שעובר על כל תמונה, מבין מה יש בה, מוצא כפולות ומטושטשות, ומסדר את הכול בתיקיות לפי נושא. הוא לא מוחק ולא מזיז אף תמונה.

![מסדר הגלריה: קיר התמונות נשאב לליבה ועף לאלבומים](assets/demo.gif)

| מה הוא עושה | מה מקבלים |
|---|---|
| מזהה מה יש בכל תמונה | תיקיות לפי נושא: משפחה, חברים, אוכל, עבודה, קבלות, דברים ששמרתם, צילומי מסך |
| מוצא כפולות | מכל סדרה של אותו רגע נשארת הכי חדה, והשאר בתיקייה "לבדיקה לפני מחיקה" |
| מוצא מטושטשות וצילומי כיס | גם הן מחכות לבדיקה, לא נמחקות |
| מזהה טיולים לפי המיקום | ימים רצופים רחוק מהבית = אלבום טיול עם החודש והשנה |
| ממשק מונפש | כל התמונות שלכם עפות לאלבומים בדפדפן. מצלמים את המסך ויש סרטון |

## התקנה

1. צריך [Claude Code](https://claude.com/claude-code) מותקן במחשב.
2. פותחים אותו ומדביקים:

> התקן לי את הסקיל "מסדר הגלריה" מהכתובת https://github.com/Brain-ai-biz/gallery-sorter : הורד את הריפו לתיקיית הסקילים שלך, ~/.claude/skills/gallery-sorter (אם אין git במחשב, הורד את קובץ ה-zip של הריפו וחלץ אותו לשם). אחר כך הפעל את הסקיל, תסביר לי מה אתה עושה, ותוביל אותי צעד אחרי צעד לסדר את הגלריה שלי. דבר איתי בעברית.

3. מכאן קלוד מוביל: מוצא לבד איפה התמונות, מכין את הסביבה, מבקש מפתח של Gemini (ומסביר איך יוצרים אותו בדקה), ומריץ קודם ניסיון על 200 תמונות.

## האם זה יעבוד אצלי?

כן, עם **אייפון וגם אנדרואיד**, על **מק וגם ווינדוס**. הדרכים הכי קלות:

| יש לך | מה עושים |
|---|---|
| אייפון + מק עם תמונות iCloud | כלום. הסקיל קורא ישר מאפליקציית Photos |
| אייפון + ווינדוס | iCloud for Windows מוריד את התמונות לתיקייה, או העתקה בכבל |
| Google Photos (אנדרואיד או כל אחד) | [takeout.google.com](https://takeout.google.com) ← רק Google Photos ← מורידים את קובצי ה-zip. **לא צריך לחלץ** |
| אנדרואיד בכבל | מעתיקים את התיקייה DCIM/Camera למחשב |

**עלות:** הסקיל חינם. הזיהוי ב-Gemini עולה בערך חצי דולר לאלף תמונות בחשבון בתשלום (יש גם מסלול חינמי). מפתח של OpenAI עובד גם.

**פרטיות:** רק עותק מוקטן (384 פיקסלים) של כל תמונה נשלח לזיהוי. במסלול החינמי של Gemini, Google רשאית להשתמש בנתונים לשיפור המוצרים שלה. בחשבון בתשלום היא לא. לגלריה עם ילדים ומסמכים, עדיף חשבון בתשלום.

```
scripts/classify.py      זיהוי (Gemini או OpenAI), כפולות, מטושטשות, טיולים

scripts/organize.py      תוכנית, ואחרי אישור העתקה לתיקיות
studio/studio.html       הממשק
```
