# עריכת Blueprint ב-Make

כלל מרכזי: **שינוי אחד = שתי הגרסאות + בדיקת פילטרים + רשימת בדיקה לייבוא.** כל blueprint שמוסרים חייב להיות JSON תקין שאפשר לייבא, יחד עם רשימת בדיקות.

## צעדים

1. **קודם שומרים את ה-JSON לקובץ.** המשתמש הדביק blueprint? שמור מיד לקובץ בתיקייה `blueprints/` בפרויקט (צור אותה אם חסרה), בשם התרחיש. בקש ממנו בפעם הבאה לייצא ולהניח שם קבצים במקום להדביק. ערוך על הדיסק. לעולם אל תבקש הדבקה חוזרת.
2. **מצא את שתי הגרסאות.** לרוב לתרחיש יש גרסת ייצור וגרסת טסט. לפני עריכה, שאל או בדוק אילו קיימות. החל כל שינוי על **שתיהן**, אלא אם המשתמש אמר "רק טסט". בדוח ציין במפורש: "הוחל על: ייצור, טסט".
3. **בצע את העריכה.**
4. **הרץ את רשימת הבדיקה למטה, בכל פעם**, גם בשינוי "קטן".
5. **מסור:** נתיב לקובץ JSON מוכן לייבוא, טבלת מזהי המודולים ששונו, והודעות הבדיקה המדויקות שהמשתמש צריך לשלוח כדי לאמת.

## רשימת בדיקה (אחרי כל עריכה)

- **פילטרים:** השווה פילטרים לפני ואחרי. החלפת מודול ושינוי ראוטר מוחקים פילטרים בשקט. ספור לפני ואחרי: המספרים חייבים להתאים, או שההפרש מכוון ומוצהר.
- **מזהי מודולים:** כל `id` שמופיע במיפויים (`{{N.field}}`) חייב להתקיים בזרימה. אחרי מחיקה או הוספה של מודולים, חפש הפניות למזהים שהוסרו.
- **בלעדיות בראוטר:** אם מסלול אחד אמור להחליף אחר ולא להתלוות אליו (למשל "שלח תמונה **במקום** טקסט"), בשני המסלולים צריכים להיות פילטרים שלא יכולים להתקיים יחד. פילטר בצד אחד בלבד גורם לשליחה כפולה.
- **פורמטי מזהים ב-WhatsApp:** שיחה פרטית מסתיימת ב-`@c.us`, קבוצה ב-`@g.us`. פילטר של קבוצה בודק `@g.us`, לא את מספר השולח. פילטר מספרי בדיקה צריך להחריג מספרים מזויפים ידועים.
- **שדות ב-Data Store:** כל שדה שנקרא או נכתב חייב להיות במבנה ה-Data Store. הוספת שדה חדש? אמור למשתמש להוסיף אותו גם ל-Data Store של **הטסט**.
- **וובהוקים וחיבורים:** blueprint שהודבק נושא מזהי webhook וחיבור אמיתיים. שמור אותם כמו שהם, ואל תחליף ב-placeholder אלא אם ביקשו.
- **JSON תקין:** פרסר את הקובץ הסופי לפני המסירה. לעולם אל תמסור JSON שלא נפרסר.

## הערות WhatsApp Cloud

- הודעות מחוץ לחלון של 24 שעות דורשות תבניות מאושרות.
- שליחת מדיה דורשת כתובת URL ציבורית שאפשר להוריד ישירות. קישורי שיתוף של Google Drive לא עובדים. כתובת ישירה כן.
- יצירת קבוצה דרך `/groups`.

## טעויות נפוצות

| טעות | תיקון |
|------|-------|
| עורכים רק ייצור או רק טסט | תמיד שניהם, ומדווחים |
| פילטר נעלם בהחלפת מודול | השוואת מספר פילטרים |
| "שלח תמונה במקום טקסט" שולח את שניהם | פילטרים בלעדיים בשני המסלולים |
| מפנים לשדה שלא קיים ב-Data Store | רשימת שדות חדשים ליצירה (ייצור וטסט) |
| לוגיקת קבוצה מסננת לפי `@c.us` | קבוצות הן `@g.us` |
| קישור Drive כ-URL של מדיה | רק כתובת הורדה ישירה |
| מבקשים מהמשתמש להדביק שוב | עורכים את הקובץ בדיסק |
