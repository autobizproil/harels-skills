# עזרה: קיצור

הצג את הכרטיס הזה כשמפעילים אותו. חד-פעמי: אל תשנה מצב, אל תכתוב קבצי דגל ואל תשמור כלום. תענה בסגנון קיצור.

## מצבים

| מצב | הפעלה | מה משתנה |
|-----|-------|----------|
| **kitzur** | `/kitzur` | הסגנון. התשובה קודם, בלי קישוטים, כל עובדה נשמרת. ברירת מחדל. |
| **ultrakitzur** | `/ultrakitzur` (כינוי `/kitzur ultra`) | בלי דקדוק. חלקי משפט, מילה אחת כשמספיק, כל עובדה פעם אחת. |
| **megakitzur** | `/megakitzur` (כינוי `/kitzur mega`) | לשון חז"ל. הרבה פחות מילים, מונחים טכניים מילה במילה. |

המצב נשאר עד שמשנים או עד סוף הסשן.
`/kitzur status` מדווח על המצב בלי לשנות אותו.

## הפעלה בשפה רגילה

אפשר גם בלי פקודה: "מצב קצר", "תדבר קצר", "תענה קצר", "פחות טוקנים".

## כיבוי

אמור "עצור קיצור" או "מצב רגיל". להמשיך בכל רגע עם `/kitzur`.

## שפה

עברית כברירת מחדל. הסגנון נדחס, לא השפה. מונחים טכניים, קוד, פקודות, סוגי commit ומחרוזות שגיאה נשארים מילה במילה.

## ברירת מחדל

ברירת המחדל היא `kitzur`. לשינוי:

**משתנה סביבה** (עדיפות עליונה):
```bash
export KITZUR_DEFAULT_MODE=ultrakitzur
```

**קובץ הגדרות** (`~/.config/kitzur/config.json`):
```json
{ "defaultMode": "ultrakitzur" }
```

להפעלה ידנית בלבד ב-Claude Code, הגדר `defaultMode` ל-`manual`: הסשנים מתחילים כבויים, ו-`/kitzur` או "תדבר קצר" מפעילים. `off` מכבה גם הפעלה אוטומטית וגם `/kitzur` חשוף. `manual` הוא מדיניות הפעלה, לא מצב.

סדר עדיפויות: משתנה סביבה > הגדרות ריפו > הגדרות משתמש > `kitzur`.
