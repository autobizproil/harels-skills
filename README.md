## kitzur (קיצור)

גרסה עברית של [Caveman](https://github.com/JuliusBrussee/caveman): תשובות קצרות וחדות, כל עובדה טכנית נשמרת, בלי "בשמחה!", סיכומים והסברים שלא ביקשת.

**מצבים**

| מצב | הפעלה | מה משתנה |
|-----|-------|----------|
| kitzur | `/kitzur` או "מצב קצר" | התשובה קודם, בלי טקס. ברירת מחדל. |
| ultrakitzur | `/ultrakitzur` | בלי דקדוק: חלקי משפט, כל עובדה פעם אחת. |
| megakitzur | `/megakitzur` | לשון חז"ל. ניסיוני. |

כיבוי: "עצור קיצור" או "מצב רגיל". סטטוס: `/kitzur status`.

**מה יש**

- `hooks`: הפעלה אוטומטית בתחילת כל סשן, זיהוי "מצב קצר" / "תדבר קצר" / "פחות טוקנים" / "עצור קיצור" / "מצב רגיל" בשפה רגילה, תזכורת בכל הודעה, וגם לסוכני משנה.
- `skills`: `kitzur`, `ultrakitzur`, `megakitzur`, `kitzur-commit`, `kitzur-review`, `kitzur-stats`, `kitzur-help`.
- סטטוסליין עם תג המצב (`[KITZUR]`).

## התקנה

הדרך הכי פשוטה: שלח ל-Claude את הקישור לריפו וכתוב "תתקין את זה". הוא יקרא את [INSTALL.md](INSTALL.md), יסביר מה הוא עומד לשנות, ויבקש אישור.

ידנית:
```bash
git clone --branch v0.1.1 --depth 1 https://github.com/autobizproil/harels-skills.git
cd harels-skills
node install.js
```

או כ-plugin:
```
/plugin marketplace add autobizproil/harels-skills
/plugin install harels-skills@harels-skills
```

דורש Node.js. הסרה: `node install.js --uninstall`.

## כמה טוקנים זה חוסך?

נמדד פעם אחת, בעברית: עשר שאלות (תכנות ועסקים), מודל Sonnet, סביבה נקייה בלי הגדרות אחרות, טוקני פלט כולל חשיבה. הקוד והתוצאות ב-[eval/](eval/).

| תנאי | חציון טוקני פלט | סכום | מול ללא הוראה |
|------|-----------------|------|----------------|
| ללא הוראה | 1060 | 11,373 | |
| הוראה פשוטה "ענה בקצרה." | 598 | 5,966 | -48% |
| `kitzur` | 687 | 7,930 | -30% |
| `ultrakitzur` | 564 | 6,362 | -44% |

**המסקנה הישרה:** `kitzur` חוסך טוקנים, אבל **פחות** מהמשפט הפשוט "ענה בקצרה." `ultrakitzur` בערך שווה לו. לא מדדנו איכות (האם התשובות נשארו נכונות ושלמות), רק אורך, ורק הרצה אחת של 10 שאלות, כך שההפרשים הקטנים בתוך הרעש. החיסכון הוא בטוקני **פלט** בלבד. אם המטרה היחידה היא פחות טוקנים, "ענה בקצרה." מספיק. הערך של הסקילים כאן הוא ההתנהגות (התשובה קודם, שליליות נשמרות, קוד מדויק, יציאה מהמצב באזהרות), לא החיסכון.

**ברירת מחדל:** ההתקנה מגדירה `manual`: הקיצור מופעל רק כשמבקשים ("מצב קצר" או `/kitzur`). להפעלה בכל סשן: `node install.js --always-on`.
